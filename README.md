# Collateral Casters

FPS 3D web centré sur le chaos, les combos destructeurs et l'utilisation du décor comme arme.

Déjà intégré :
- Three.js + TypeScript + Vite.
- Pointer lock, ZQSD/WASD, saut, dash, FOV et sensibilité.
- 6 sorts : Impact, Braise, Givre, Faille, Arc, Nova.
- Combo Givre + Impact = Fracture glaciale.
- Télékinésie avec F et projection d'objets.
- Barils explosifs, murs fragiles, cristaux et éliminations indirectes.
- Grande arène avec plateformes et verticalité.
- Sentinelles, spectres volants, kamikazes et boss.
- 3 vagues par district.
- Améliorations temporaires entre vagues.
- Score, meilleur score et progression sauvegardés dans localStorage.
- Direction visuelle toon/anime.

Développement : npm install puis npm run dev.
Build : npm run build.
